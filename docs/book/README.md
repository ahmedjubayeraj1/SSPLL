# SSPLL + FFNC for SKY130 - design documentation

Living documentation (roadmap step 10). It grows with the project: every phase fills its chapter, and the final
version is the request-17 deliverable and the Rule 15 behavioural documentation.

Each topic is written as: **What happens** (the observation), **How it happens** (the mechanism, with equations), **Why it happens** (the physical reason), then a figure or simulation you can reproduce.
