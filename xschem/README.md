# xschem/

Schematics of the 5 V-device design, one folder per block: `vco_hv/`, `cco_hv/`, `refbuf_hv/`, `clkgen_hv/`,
`sspd_hv/`, `sscp_hv/`, `lf_hv/` (loop filter, from `design/loop/`), `fll_hv/` (FLL; its standard cells come from the PDK's `sky130_stdcells` symbols), `d2s_hv/` (diff-to-SE amplifier). They are generated by `design/<block>/schematics_hv.py` (with `tools/xsch.py`, which also
checks the drawing: no overlapping text, wires or pins), so a design change and its schematic stay in step.

`xschemrc` starts with

    source $env(PDK_ROOT)/$env(PDK)/libs.tech/xschem/xschemrc
    append XSCHEM_LIBRARY_PATH :[file dirname [file normalize [info script]]]

so the PDK symbols resolve on any machine.

- `lvs.sh <cell.sch> <reference.spice> <cell>`: netlists a schematic with xschem and compares it with the simulated
  netlist using netgen (topology, pin lists and device properties). `python3 tools/lvs_hv_all.py` runs it on every cell.
- `render.sh <cell.sch> <out.png> [WxH]`: PNG of a schematic (the figures in `docs/img/`).
- `netlist/`: generated netlists and LVS reports (not in git).
